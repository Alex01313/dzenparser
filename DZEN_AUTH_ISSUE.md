# Проблема с авторизацией Dzen / Dzen Auth Issue

## Проблема / Problem

При попытке спарсить ссылку `https://dzen.ru/a/aTsmd_bGr2aapkGO` парсер выдает ошибку:

> "Could not extract article text. The page structure might have changed or the article may not be available."

## Причина / Root Cause

Dzen перенаправляет все неавторизованные запросы на страницу SSO (Single Sign-On):

```
https://dzen.ru/a/aTsmd_bGr2aapkGO
   ↓ (redirect 302)
https://sso.passport.yandex.ru/push?uuid=...&retpath=...
```

Эта страница SSO:
- Не содержит текста статьи
- Содержит только JavaScript для авторизации
- Имеет размер ~2400 байт (очень маленький)
- Не имеет `<article>`, `<p>`, или другого контента

## Возможные причины / Possible Reasons

### 1. Статья требует авторизации
Некоторые статьи Dzen доступны только авторизованным пользователям.

### 2. Статья не существует / удалена
ID статьи может быть неверным или статья была удалена.

### 3. Географические ограничения
Статья может быть недоступна из вашего региона.

### 4. Ограничения для ботов
Dzen может блокировать автоматические запросы.

## Обновление парсера / Parser Update

Мы можем добавить проверку на редиректы SSO:

### Новая функция в zen_parser_gui.py:

```python
def check_if_auth_required(self, response):
    """Check if page requires authentication"""
    # Check if redirected to SSO
    if 'sso.passport.yandex.ru' in response.url:
        return True, "Article requires authentication"
    
    # Check if page is too small
    if len(response.content) < 5000:
        return True, "Page too small - likely redirect/error"
    
    # Check for auth-related keywords
    if b'auth' in response.content.lower() or b'login' in response.content.lower():
        return True, "Page contains auth keywords"
    
    return False, "OK"
```

## Техническая информация / Technical Details

### Что происходит:

```
1. Парсер → GET https://dzen.ru/a/aTsmd_bGr2aapkGO
2. Dzen → 302 Redirect → https://sso.passport.yandex.ru/push?...
3. SSO страница → JavaScript redirect (form.submit())

5. Парсер → Нет <article>, нет <p> → Ошибка ❌
```
