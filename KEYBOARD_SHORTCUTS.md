# Keyboard Shortcuts / Горячие клавиши

## URL Entry Field / Поле ввода URL

### macOS

| Shortcut | Action | Действие |
|----------|--------|----------|
| `⌘ Cmd + V` | Paste URL | Вставить URL |
| `⌘ Cmd + C` | Copy URL | Копировать URL |
| `⌘ Cmd + X` | Cut URL | Вырезать URL |
| `⌘ Cmd + A` | Select all | Выделить всё |
| `Right-Click` | Context menu | Контекстное меню |

### Windows / Linux

| Shortcut | Action | Действие |
|----------|--------|----------|
| `Ctrl + V` | Paste URL | Вставить URL |
| `Ctrl + C` | Copy URL | Копировать URL |
| `Ctrl + X` | Cut URL | Вырезать URL |
| `Ctrl + A` | Select all | Выделить всё |
| `Right-Click` | Context menu | Контекстное меню |

## Context Menu / Контекстное меню

Right-click in the URL field shows a menu with:
- **Cut** - Cut selected text
- **Copy** - Copy selected text
- **Paste** - Paste from clipboard
- **Select All** - Select all text in field

При клике правой кнопкой в поле URL появляется меню:
- **Cut** - Вырезать выделенный текст
- **Copy** - Копировать выделенный текст
- **Paste** - Вставить из буфера обмена
- **Select All** - Выделить весь текст в поле

## Quick Reference / Быстрая справка

### Most Used / Чаще всего используемые:

**macOS:**
- `⌘V` - Paste URL / Вставить URL ⭐
- `⌘A` - Select all / Выделить всё

**Windows/Linux:**
- `Ctrl+V` - Paste URL / Вставить URL ⭐
- `Ctrl+A` - Select all / Выделить всё

### Alternative Methods / Альтернативные методы:

If keyboard shortcuts don't work:
1. Right-click in URL field
2. Select "Paste" from menu
3. URL will be inserted

Если горячие клавиши не работают:
1. Кликните правой кнопкой в поле URL
2. Выберите "Paste" из меню
3. URL будет вставлен

## Tips / Советы

### English:
- The URL field supports all standard text editing operations
- Right-click always shows the context menu
- Both Cmd (macOS) and Ctrl (Windows/Linux) shortcuts work
- You can type URLs manually if paste doesn't work
- The context menu is accessible via right-click or middle-click

### Русский:
- Поле URL поддерживает все стандартные операции редактирования текста
- Правый клик всегда показывает контекстное меню
- Работают и Cmd (macOS), и Ctrl (Windows/Linux) сочетания
- Можно вводить URL вручную, если вставка не работает
- Контекстное меню доступно по правому или среднему клику мыши

## Troubleshooting / Решение проблем

### Paste doesn't work / Вставка не работает

**Try these alternatives / Попробуйте альтернативы:**

1. **Right-click method / Метод с правой кнопкой:**
   - Right-click in URL field
   - Select "Paste"

2. **Try Ctrl instead of Cmd / Попробуйте Ctrl вместо Cmd:**
   - Press `Ctrl+V` (even on macOS)

3. **Type manually / Введите вручную:**
   - Click in URL field
   - Type the URL

4. **Check clipboard / Проверьте буфер обмена:**
   - Try pasting in another app first
   - Copy the URL again

### Context menu doesn't show / Контекстное меню не появляется

1. **Make sure you're clicking in the URL field / Убедитесь, что кликаете в поле URL**
2. **Try middle-click as alternative / Попробуйте средний клик**
3. **Restart the application / Перезапустите приложение**
