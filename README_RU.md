# Парсер статей Яндекс.Дзен

Python приложение с графическим интерфейсом для извлечения текста статей из Яндекс.Дзен. Приложение поддерживает macOS и извлекает **только текст статьи**, отфильтровывая навигацию, рекламу, комментарии и другие элементы страницы.

## Особенности

- **Удобный GUI**: Чистый и интуитивный интерфейс на основе tkinter
- **Проверка URL**: Валидация ссылок Яндекс.Дзен перед парсингом
- **Умное извлечение**: Извлекает только текст статьи, фильтруя:
  - Навигационные меню, шапку и подвал сайта
  - Кнопки социальных сетей и виджеты
  - Комментарии
  - Рекламу и промо-контент
  - Похожие статьи и рекомендации
  - Уведомления о cookies
  - Боковые панели
- **Копирование в буфер**: Удобное копирование извлеченного текста одним кликом
- **Обработка ошибок**: Подробные сообщения об ошибках сети и парсинга
- **Совместимость с macOS**: Полностью протестировано на macOS

## Требования

- Python 3.8 или выше
- Интернет-соединение для загрузки статей

## Установка

### 1. Скачайте репозиторий

```bash
git clone <url-репозитория>
cd <директория-репозитория>
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate  # На macOS/Linux
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

## Использование

### Запуск приложения

**Вариант 1: Скрипт запуска (рекомендуется для macOS)**
```bash
./run.sh
```

**Вариант 2: Прямой запуск**
```bash
python3 zen_parser_gui.py
```

### Как пользоваться

1. **Запустите приложение** одной из команд выше
2. **Введите URL статьи** Яндекс.Дзен в поле ввода
   - Поддерживаемые домены: `zen.yandex.ru`, `dzen.ru`, `zen.yandex.com`
3. **Нажмите "Parse Article"** для извлечения текста
4. **Просмотрите извлеченный текст** в основной текстовой области
5. **Нажмите "Copy to Clipboard"** для копирования текста
6. **Нажмите "Clear"** для сброса интерфейса

## Как работает извлечение

Парсер использует интеллектуальные методы для извлечения **только текста статьи**:

### Приоритет методов извлечения:

1. **JSON-LD структурированные данные** (самый точный)
   - Извлекает данные из метаданных статьи
   - Самый надежный метод, когда доступен

2. **Анализ тега `<article>`**
   - Точное извлечение контента из HTML элементов
   - Удаляет вложенные элементы, не относящиеся к статье

3. **Специфичные для Дзен селекторы**
   - Использует CSS-селекторы, характерные для структуры Яндекс.Дзен
   - Повышенная точность для статей Дзена

4. **Умная фильтрация**
   - Автоматически удаляет:
     * Навигационные меню, шапки и подвалы
     * Кнопки соцсетей и комментарии
     * Рекламу и промо-контент
     * Похожие статьи и боковые панели
     * Уведомления о cookies и всплывающие окна
     * UI элементы (кнопки, короткие тексты)

### Фильтрация "шума"

Парсер автоматически отфильтровывает фразы UI на русском и английском:
- **Русский**: "Подписаться", "Поделиться", "Читать далее", "Показать", "Скрыть"
- **Английский**: "Subscribe", "Share", "Read more", "Click here"

## Обработка ошибок

Приложение обрабатывает различные сценарии ошибок:

- **Неверные URL**: Предупреждение при неправильном формате или не-Дзен ссылке
- **Сетевые ошибки**: Обработка таймаутов и проблем с подключением
- **HTTP ошибки**: Обработка 404 (Не найдено), 403 (Доступ запрещен) и других ошибок
- **Ошибки парсинга**: Корректная обработка случаев, когда текст статьи не может быть извлечен

## Решение проблем

### Приложение не запускается
- Убедитесь, что установлен Python 3.8+: `python3 --version`
- Проверьте установку зависимостей: `pip install -r requirements.txt`
- На macOS убедитесь, что доступен tkinter (обычно идет с Python)

### Текст не извлекается
- Проверьте правильность URL и существование статьи
- Проверьте интернет-соединение
- Структура статьи могла измениться; Дзен иногда обновляет HTML структуру

### Проблемы с macOS
- При ошибке "Python is not installed as a framework" используйте `pythonw` вместо `python3`
- Убедитесь, что используете системный Python или правильно настроенную установку

## Технические детали

### Зависимости
- **requests**: Для HTTP-запросов к страницам статей
- **beautifulsoup4**: Для парсинга HTML контента
- **lxml**: Парсер для BeautifulSoup (быстрее и надежнее)
- **tkinter**: GUI фреймворк (входит в состав Python)

### User Agent
Приложение использует user agent macOS Chrome для обеспечения совместимости с серверами Яндекс.Дзен.

## Ограничения

- Парсер полагается на текущую HTML структуру Дзена. При значительных изменениях может потребоваться обновление.
- Некоторые статьи с активной загрузкой через JavaScript могут парситься не полностью
- Контент с гео-ограничениями или только для подписчиков может быть недоступен
